# Lokaler Kurs-Prüfer

Öffne den Kursordner mit `aufgabe.py` und `tests/test_aufgabe.py` in VS Code.
Starte **Kurs: Aufgabe prüfen** über die Befehlspalette.
Die Erweiterung speichert geöffnete Dateien und startet die Python-Tests als Task.
Die Ausgabe erscheint im Terminal: `OK` bedeutet Erfolg, `FAILED` einen Fehler.

Python 3 muss über den Befehl `python3` erreichbar sein.
Die Tests führen den Code des Kurses direkt mit deinen Benutzerrechten aus.
Der Befehl startet erst auf deinen Aufruf und benötigt einen vertrauenswürdigen Arbeitsbereich.

Dies ist ein lokales Beispiel für das Installationsbuch. Der Herausgebername
`lokale-kurse` ist eine lokale Paketkennung und kein registrierter Marketplace-Herausgeber.
