# Kurs-Prüfer: Quadratsumme

Implementiere `quadratsumme(werte)` in `aufgabe.py`. Die Eingabe ist eine
endliche Folge ganzer Zahlen. Auch ein Generator muss funktionieren.
Jede Zahl wird zuerst quadriert, dann werden die Ergebnisse addiert.
Für eine leere Eingabe ist das Ergebnis 0. Die Eingabe darf nicht verändert werden.

Führe im Kursordner aus:

```bash
python3 -m unittest discover -s tests -p test_aufgabe.py -v
```

Anfangs schlagen die Tests absichtlich fehl. Ändere die Aufgabe, nicht die Tests.
Die Anleitung zum Bauen der Erweiterung steht im mdBook-Kapitel `kurs-pruefer.md`.
