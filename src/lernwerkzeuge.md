# Kurse und Lernwerkzeuge

Diese Übersicht führt zu Lernangeboten und lokalen Übungswerkzeugen für Ubuntu 26.04 LTS (amd64).

## Anleitung auswählen

1. Wähle das Werkzeug nach seiner Aufgabe. Webangebote erhalten eine Zugangsanleitung; lokal installierbare Werkzeuge erhalten Installationsbefehle.

   | Werkzeug | Aufgabe und Betriebsart | Anleitung |
   |---|---|---|
   | JetBrains Academy Plugin | Kursaufgaben in einer kompatiblen JetBrains-IDE | [Plugin](jetbrains-academy.md) |
   | Rustlings | Rust-Übungen im Terminal | [Rustlings](rustlings.md) |
   | Exercism-CLI | Aufgaben lokal bearbeiten, Konto für Downloads | [Exercism](exercism.md) |
   | CodeRoad | Git-basierte interaktive Kurse in VS Code | [CodeRoad](coderoad.md) |
   | CodeTour | Geführte Erläuterungen durch Quelldateien | [CodeTour](codetour.md) |
   | GitHub Skills | Übungsrepositorys mit GitHub Actions | [Webzugang](github-skills.md) |
   | Eigener Kurs-Prüfer | Python-Tests im Terminal und per VS-Code-Befehl | [Eigenbau](kurs-pruefer.md) |
   | Anki mit FSRS | Lernkarten und zeitlich verteilte Wiederholungen | [Anki](anki.md) |
   | Execute Program | Onlinekurse mit Wiederholungen, begrenzter Gratiszugang | [Webzugang](execute-program.md) |
   | Python Tutor | Programmablauf schrittweise visualisieren | [Webzugang](python-tutor.md) |
   | js-parsons | Codeblöcke lokal im Browser ordnen | [Bibliothek](js-parsons.md) |
   | roadmap.sh | Lernpfade im Browser | [Webzugang](roadmap-sh.md) |
   | project-based-learning | Linkliste als lokale Git-Kopie | [Projektideen](project-based-learning.md) |
   | build-your-own-x | Linkliste für Nachbauprojekte | [Selbstbauideen](build-your-own-x.md) |
   | kurs-lernen.js | Eigener Browserkurs mit Vorhersage, Parsons, Karten und Pfad | [Eigenbau](kurs-lernen.md) |

2. Folge der jeweiligen Anleitung in einem neuen Beispielordner. Die Kapitel zeigen auch, wie du die Einrichtung prüfst und wieder entfernst.

3. Verwende für Ergänzungen die vollständigen Quellcodearchive aus den Eigenbau-Kapiteln. Sie enthalten eigene kleine Beispiele. Der Kartenplan von kurs-lernen.js ist bewusst einfach; für den FSRS-Planer verwende Anki.

Die Anleitungen legen keine externen Konten an, buchen keine Zugänge und veröffentlichen keine Kurse. Ein kostenloses Plugin oder eine frei lizenzierte Linkliste garantiert keinen kostenlosen Zugang zu allen verlinkten Inhalten.
