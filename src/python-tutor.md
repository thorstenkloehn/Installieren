# Python Tutor

Python Tutor zeigt die Ausführung kleiner Programme schrittweise mit Variablen und Datenstrukturen.

Für Ubuntu 26.04 LTS (amd64). Hier wird der kostenlose Webzugang beschrieben. Der Code wird an den Anbieter übertragen; verwende dafür eigene, unkritische Beispiele. Eine lokale Serverinstallation wird nicht eingerichtet.

## Einrichtung

### 1. Visualizer öffnen

Öffne [Python Tutor](https://pythontutor.com/visualize.html) im Browser und wähle Python.

### 2. Eigenes Beispiel eingeben

Das Programm verändert eine Liste über zwei Namen. Es eignet sich, um gemeinsame Referenzen zu beobachten.

````python
zahlen = [3, 6]
zweiter_name = zahlen
zweiter_name.append(9)
print(zahlen)
````

### 3. Visualisierung starten

Klicke Visualize Execution, damit der Ausführungsablauf berechnet wird.

### 4. Schrittweise vorgehen

Gehe mit der Vorwärtsschaltfläche jeweils eine Zeile weiter und beobachte, dass beide Namen auf dieselbe Liste zeigen.

## Einrichtung prüfen

### 1. Ergebnis vergleichen

Am Ende muss die Ausgabe [3, 6, 9] erscheinen. Gehe anschließend einen Schritt zurück und prüfe die vorherige Ansicht.
